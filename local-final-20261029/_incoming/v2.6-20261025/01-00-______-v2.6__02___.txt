══ 一、⚠ C02 有一个能白拿奖励的口子，先修 ══

  环任务这几条领奖路径只认"在不在 accepted 里"，而接任务不看领过没有、也不看是不是环任务：
    acceptCircleTask(X) → circleTaskAward(X) 发奖 → 再 acceptCircleTask(X) → 再领 …… 无限循环
  同样能刷：rogueAcceptTask+getRogueFinishTaskAward、delegateTask（也会把任意 X 塞进 accepted）+ 任一领奖口。
  还有跨口重复：主线任务 X 用 getFinishTaskAward 领过（记在 s.rewarded），
  再走 acceptCircleTask(X)+circleTaskAward(X) 又能领一遍；quickFinishTask 发了奖但不记 rewarded，
  之后 getFinishTaskAward 还能再发一次。
  你们的冒烟测的是"领完马上再领被拒"，没测"领完再接再领"，所以没抓到。

  修法（一处共用，几行）：所有发任务奖的口子共用一本账 s.rewarded：
    function canClaim(s, tid) {
      s.rewarded = s.rewarded || [];
      if (!isRepeatTask(tid)) return s.rewarded.indexOf(tid) < 0;
      var d = todayKey();                       // 你们已有的按天键
      if (!s.circleDay || s.circleDay.d !== d) s.circleDay = { d: d, n: 0 };
      return s.circleDay.n < CIRCLE_DAILY_MAX;  // 环任务每日上限：先用 circle_task 表/客户端 cNum 上限，取不到先写 20
    }
    function markClaim(s, tid) {
      if (!isRepeatTask(tid)) { if (s.rewarded.indexOf(tid) < 0) s.rewarded.push(tid); }
      else s.circleDay.n++;
    }
  用在：circleTaskAward、getCircleTaskAward、getRogueFinishTaskAward、quickFinishTask
       （quickFinishTask 在**扣元宝之前**判 canClaim，不过就回 2 且不扣钱）。
  接任务口（acceptCircleTask / rogueAcceptTask / delegateTask）：tid 不在 BZ_TASKS，或非重复任务且已 rewarded，
       回 eRet:6、不动档。
  冒烟补一条：接→领→再接→再领，第二次必须被拒、存档逐字节不变；再补一条"主线领过→走环任务口再领"被拒。
