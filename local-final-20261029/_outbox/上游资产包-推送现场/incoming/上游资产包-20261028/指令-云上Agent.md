## 五、环境注意（若你在本机跑 git）

- 本机 hosts 把 github 系域名全指到 127.0.0.1，出网必须走代理 `http://127.0.0.1:7890`（Clash）。
  `.gitconfig` 已配好 `http.https://github.com.proxy=http://127.0.0.1:7890`（2026-10-28 修过，原来写死 7897 是死端口）；git 凭据已在 Windows 凭据管理器，push 不需要再贴 token。
- Clash 节点偶发掉线（表现为 `000`/TLS 握手失败），等一会重试即可，别当 push 失败。
- `gh auth login` 收不了当前 token（缺 `read:org` scope）；需要 gh 命令时用 `$env:GH_TOKEN` 环境变量。
