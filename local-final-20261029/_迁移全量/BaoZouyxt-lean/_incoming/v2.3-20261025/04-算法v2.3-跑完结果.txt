四、误报或漏报最明显的 3 处（各一句话）
1（漏报）GetMarketList.market：该标「不能用 0 兜底」；我们发 0 → 客户端 for..in 零次迭代 → 货架全空。
2（漏报）passCardData.passObj：该标「不能安全兜底」；缺了 PassCardUI 每帧 TypeError（实测 2 秒 110 次）。
3（漏报）getBigGrowupData 的空 growObj：该标「数据空会重发请求」；工具只标了 getPayState，
   而真正把界面 lockScreen 锁死的是它（scripts2.js:46175 changePage → reqBigGrowUpData）。

补充：误报暂未找到明显一例。已知「0 是合法值」的对照项（BeginTraining.isCollective、
getActivityCounts.dataArr）都没有被误标，说明零值白名单那类没被误伤。
覆盖率是结构性原因：shape-hints 只覆盖 104 个动作（inScope 700，约 15%），
上面三处漏报都落在覆盖范围之外。

六、一个环境坑（别的下游可能也踩）
PowerShell 的 `>` 重定向会把 panel.json 写成 UTF-16（首字节 FF FE），relate.py 直接报
  UnicodeDecodeError: 'utf-8' codec can't decode byte 0xff in position 0
改用 Start-Process -RedirectStandardOutput（或 cmd /c 重定向）即可。建议 README 加一句。
