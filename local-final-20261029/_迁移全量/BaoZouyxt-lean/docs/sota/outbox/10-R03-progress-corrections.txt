▍更正 3：我上批报的"死任务 2629"作废
`judgeTaskCondition`（index 134085-134092）的真实语义是**阈值型**：
```
e = Pre-Require.split("|"); o = e.length-1; i = e[o];   // 末段 = 阈值
for (r=0; r<o; r++) if (checkAttribute(e[r])) n++;
if (0 == i) { if (n == o) return true }   // 阈值 0 → 全部满足
else if (i <= n) return true              // 阈值 k → 至少 k 个
```
329 个任务带非 0 阈值（例：`"1,100030,0|1,100040,0|1"` = 两条里任一条）。
我重算三种口径：任一父可达 = 2211 / 全部满足 = 721 / 阈值语义 = 752。
三个数都不可信（4840 个任务里 85% 不可达 = 我的图没建模真正入口），**死任务口径作废，不用于任何过滤**。
