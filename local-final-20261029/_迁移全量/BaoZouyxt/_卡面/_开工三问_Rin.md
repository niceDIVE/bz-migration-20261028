## 姿势设计说明（为什么这么设计）

原始提示词给的姿势是 `curled slightly inward like an aloof cat`（向内蜷如猫）+ 平板抱在躯干前。**「抱在躯干前」正是诗织踩过的双臂交叉陷阱的入口**，且向内蜷在 1:1.5 竖构图的中近景里会被裁掉一半，读不出来。

故改为：**平板斜举到脸侧、只露半张脸隔着屏幕看你**。
- 语义上完全符合设定：无口黑客躲在屏幕后面观察你，这正是她的性格
- 结构上天然不对称（一手高举、一手垂落），不可能滑向抱胸
- 中近景取景下平板、脸、颈挂耳机、抽绳同框，道具锚点全部可见

# v2 追加（用户授权调整外观）

## 改了什么

| 项 | v1 | v2 | 理由 |
|---|---|---|---|
| 视线 | looking_at_viewer 看观众 | **looking_down(95511) 低头看屏幕**，不看观众 | 「无口、疏离如猫」的性格动作就是**不理你**；且与杏（仰视略偏）、诗织（迎视俯视）形成三种不同的视线关系，系列辨识度直接拉开 |
| 光源 | 无 | 屏幕冷青辉光打在脸和镜片上（glowing + NL） | 天才黑客的"被屏幕照亮"是最经济的性格叙事 |
| 糖球 | 只出细棍（有误读成烟的风险） | swirl_lollipop(3434) + NL "round pastel candy ball" | 保留原设定"糖棍"的同时把糖球实体化 |
| 取景 | 偏宽，露到卫衣下摆+大腿 | 锁死中近景：删掉 NL "hangs on her like a mini-dress"（等于喊模型拉远镜头），负面新增 	highs(560812) / are_legs(134676) / pleated_skirt(497043) | 用户标准是中近景，"下摆失踪"这类描述与景别要求互相拆台 |
| 妆感 | 模型自加重眼线，偏哥特 | NL "clean minimal eye makeup" + "soft light eyelashes" | 洋娃娃该是干净冷白，不是浓妆 |

## 姿势结构

一手举屏、一手垂落，**高度与方向都分离**，从结构上排除双臂交叉的可能（诗织两轮的教训）。
"抱在躯干前"这类语义入口一律不写。

## 本批词库处置（0-B）

新用已验规范词：looking_down(95511) / swirl_lollipop(3434)。
新入负面的规范词：	highs(560812) / are_legs(134676) / pleated_skirt(497043)，均为库内验证过的写法。
"无口"的神态仍走 expressionless(118027) + half-closed_eyes(93882) + closed_mouth(1156328)，deadpan/lank_expression 库内不存在故不用。
