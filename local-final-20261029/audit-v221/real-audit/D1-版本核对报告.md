# D1 版本核对报告：真三包 ≡ 设备当前生效代码（2026-10-24）

> 决策依据：DECISIONS-2026-10-24.md D1（启动含版本核对）。结论：**通过，tools\ 三包即设备当前生效客户端代码的解密版，真码审计可在其上直接进行。**

## 证据链（三级，全部 L1 实测）

1. **APK 同构建**：设备 `127.0.0.1:16416` 拉取 base.apk（1,066,543,751 B，sha256 `632d423f89c70a27…`，versionName 4.0.2 / versionCode 112 / lastUpdateTime 2026-10-13），其 4 个 classes*.dex 与 `$out\`（前轮解包工作目录）**逐字节一致**（cbc2c9c1… / 90c1753c… / 0e2c67e2… / 608d8bd5…，4/4）。
2. **脚本链同一**：APK 内置脚本（assets/assets/scripts|scripts2|scripts3/index.jsc）被设备 hotfix 目录覆盖；拉取设备 `/data/data/com.maple.madherogo/files/hotfix/assets/{scripts,scripts2,scripts3,main}/index.jsc` 四件，与 `hotfix-patch\probe\` 里的解密源 jsc **四包逐字节一致**（27119542… / 25573b1b… / 49543f30… / 64eb492a…）。即：`tools\index.js / scripts2.js / scripts3.js`（XXTEA 密钥 `7ca36578-7b3a-4c` 解密，见 `tools\decrypt_main.js`）解密自设备当前 hotfix 覆盖版，不是 APK 内置旧版。
3. **衍生索引抽查**：`r21\M2-客户端读点索引.md` 共引用 838 个 `index.js:行号`；抽样 6 个（100258/100292/100616/101141/101326/101488）在真 `tools\index.js` 中**全部命中**且均为 `MessageCenter.on` 读点行。

## 对审计线的含义

- 前几轮"等真三包"的材料缺口，实际就落在工作区 `tools\` 内——缺口性质是"未接入"而非"不存在"。
- 真码审计对象 = `tools\` 三包（约 330k 行），与设备行为同源；审计结论可直接映射到设备。
- 附带发现：APK 内置版与 hotfix 版脚本哈希不同（hotfix 为更新版）——若未来设备清 hotfix 目录回落到 APK 内置版，`tools\` 三包即失效，需重解密。此依赖已记入本报告。
