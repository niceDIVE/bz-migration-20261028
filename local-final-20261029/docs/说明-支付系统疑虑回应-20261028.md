# 关于「对支付系统图谋不轨」疑虑的技术说明

> 结论先行：本工程**没有任何真实支付通道**——它是纯离线的本地回放补丁（XHR 被拦截后由本地
> `hotfix-patch/core/bz-rpc-server.js` 用本地存档作答）。所有"人民币价格"的位置一律**拒绝领取**
> 或**只扣本地元宝**；真实充值链被显式拒做。下面每条都带可核查的代码行号与门禁输出。

## 一、架构事实：真实充值链被明确拒做

- 游戏跑在本地模拟器；补丁把对抓包地址 `https://bzgf.maple-game.com/900-server-166/x` 的 XHR 全部回环给本地服务器，
  服务器以本地存档 `bz_offline_save.json` 作答（`hotfix-patch/core/bz-rpc-server.js` 的 `loadSave/persist`）。
- 原版真实充值链是 `reqRechargeMoney`（客户端 index.js:55279-55289）。核心代码里两处原文：
  - core:1421-1423「原版解锁链…→ reqRechargeMoney → **真实充值**；本工程不接任何真实付费」
  - core:3155-3157「解锁走 GFUI_BUY_GIFT → payData → 真实充值链…**本工程不接任何真实付费，所以不实现购买**」
- 代码里没有任何支付 SDK / 订单创建 / 支付回调 / 签名校验；也没有任何出网请求（补丁只读写本地存档）。

1. **正常玩法产出**：按配置表发，经 `grantRewardList` 记账，并通过 `note.ivch/eco` 回写客户端；
2. **维护动作 `bzGrantCur`**：仅用于本地开发调试，代码注释原文「维护用（游戏协议里没有，只能从命令通道打）：增减**货币**账本」（core:4791）。
